# Meme Battle Roguelite

Free-for-all coin brawler made with Godot 4.7. Pick a meme coin, draft a weapon, two skills and an ultimate, and fight bots.

**Play:** https://lyrathesunshard.github.io/meme-battle-roquelite/

Controls: A/D move, Space jump, mouse aim, left click attack, Q/E skills, R ultimate.

This repo holds the exported web build only. Third-party assets are listed in [CREDITS.md](CREDITS.md).
